## Getting started
1.  make sure you have the [.NET SDK](https://dotnet.microsoft.com/download) installed.  
2.  clone the repository and build the project using `dotnet build`.
3.  run it from Etch.Demo with `dotnet run -c Release`.

## Collaborating
* **PRs only** - `main` must stay **functional** at all times and its history must be **readable**.
* **squash merge** - don't worry about messy commits within your branch as they'll be squashed anyway.
* **attribution** - please include `Co-authored-by:` when merging, if needed.

## Design and code style
* **performance** - prefer value types, stack allocation, and zero-allocation patterns on hot paths.
* **consistency** - check out existing abstractions within the codebase before writing your own.
* **discussion** - don't be afraid to hit me up, I'm happy to answer questions and design directions.

## Community
* **be kind** - be respectful and constructive toward everyone.
* **be curious** - don't be afraid to ask about stuff, we're all here to learn and work together.
